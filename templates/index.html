About Network IDS

Network IDS is a real-time network intrusion detection system combining a rule-based packet monitor, a trained machine-learning classifier, and automatic firewall blocking, all managed from this web dashboard.

  • Dashboard — overview of recent predictions and attack statistics.
  • Live Monitoring — starts the packet-capture monitor and streams its log.
  • Live Prediction — run a single feature vector through the ML model.
  • Upload / Analyze — batch-predict a CSV of network flow records.
  • Reports — filter, browse and export past predictions (CSV/PDF).
  • Blocked IPs — see and manage IPs blocked by the IDS.
